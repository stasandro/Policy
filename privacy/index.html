Privacy Policy

This policy covers the Future Historians production tools, including the Google API client named “Future Historians” that the channel uses to store its own video files.

Who uses the app

The app is used only by the owner of the Future Historians channel to manage the channel's own production files. It is not offered to the public and does not have user accounts.

What Google data the app accesses

  • Google Drive, scope drive.file: the app creates a folder named “Future Historians” in the owner's Drive and uploads finished episode files to it (video, subtitles, thumbnail, text). With this scope the app can only see files it created itself; it cannot read any other files in the Drive.
  • If YouTube access is enabled later, it is used only to upload and edit videos on the owner's own channel.

What is stored and where

The only thing the app keeps is an OAuth refresh token, stored in a private configuration file on the production machine and never published. No personal data, contacts or viewing data are collected, sold, shared or used for advertising.

Viewers of the channel

The app does not collect any information about viewers. Data about viewers of the YouTube channel is handled by YouTube under the Google Privacy Policy.

Google API Services User Data Policy

The use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking stops all uploads; files already uploaded stay in the Drive and can be deleted there.

Contact

Questions about this policy: through the contact details on the Future Historians YouTube channel.
